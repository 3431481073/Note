## 一、已定死的 UI / 交互

### 1. 卡片 / 视图切换

- 要做。
- 直接照搬 v12 的 3D 折叠切换，不要先做瞬时切换再后补。
- CSS 格式、变换、时间轴、缓动，原型里已经写清楚，直接复刻进现有 React 体系。

### 2. 结构树 outline

- 全要。
- 拖拽、加节点、删节点、双击改名、贝塞尔连线、点阵画布，照搬原型。
- 原型是 HTML，你正常转成现有 React 格式即可。

### 3. 节点内容面板

- 要。
- 编辑节点正文。
- 支持「＋卡片」把节点导入为便签。
- 点「＋卡片」时，询问是否添加标题；可以添加，也可以不添加。
- 节点内容面板本质上就是一个普通卡片编辑界面，**唯一区别是没有标题选项**，其他显示、编辑方式与普通卡片一致。

### 4. 结构树与内容面板的装配

- 结构树就是“节点 + 线条”构成的东西。
- 节点上只显示节点名字。
- 点击某一个节点，右边详细内容区显示它的内容。
- 右边就是普通卡片编辑界面，但没有标题。
- 节点支持放回卡片。
- 一次只选中一个节点，右边显示它。

### 5. 标签 / 项目

- 要。
- 下拉多选、新建标签、chips 展示，照搬 v12。
- 标签 / 项目只在详情编辑界面出现。
- 卡片列不显示标签行，不显示标题行，保持干净。
- 颜色规则照搬 v12：视图琥珀、项目紫、普通薄荷。

### 6. 纸张标题栏

- 有标题：在详情界面显示加粗加大的标题。
- 没标题：不要显示“标题为空”，直接把标题位置去掉，只显示正文缩略。
- 卡片列不显示标题，也不显示标签，保持简洁大气。
- 标题只在详情编辑界面出现，辅助搜索与分类用，不在卡片列堆信息。

### 7. 摘要来源

- 不用 90 字。
- 折中，20～40 字，20 字够用。
- 有标题时，正文缩略可以扫掉标题那几个字，或按实际布局动态处理。

### 8. 空态兜底

- 标签 0 条不补空。
- 视图为空就是空，不补空，不要自动造节点。
- 便签 0 条是否补空，按现有逻辑保留，但视图空态不补。
- 回收站空、搜索无结果、视图空节点，文案按实际界面另立即可。

### 9. 响应式缩放

- 要用。
- 响应式缩放保留。

### 10. 窗口

- 不是冲突，是模式驱动。
- 卡片模式：窄窗，左边内容页 + 右边卡片列。
- 视图模式：动态加宽到能容纳三栏，因为结构树必须展开。
- 切回卡片模式恢复窄窗。
- Tauri 动态 `set_size` 的置顶、居中、抖动问题，你按最优实现自行处理。

### 11. 排序

- 保持旧版 `created_at` 降序。
- 新建置顶。
- 编辑旧便签不置顶。
- 不切 `updated_at`。
- 原报告 §3.2 作废。

### 12. 恢复行为

- 留在回收站。
- 不跳回便签页。
- 不自动选中。
- v12 的“跳回并选中”不采纳。

### 13. 底部加号

- 卡片和视图地位对等。
- 卡片模式：加号 = 新建便签 / 卡片。
- 视图模式：加号 = 新建视图。
- 不是旧版固定“新建便签”，也不是 v12 单方面“视图模式新建视图”。

### 14. Launcher

- 不要。
- 我们走工作台工具栏唤起。
- 原型页面内唤出按钮不照搬。

### 15. 其他辅助交互

- `Delete` 只在视图模式删节点，卡片模式不响应。
- `Esc` 级联关闭，按 v12 原型照搬。
- Toast 位置、时长按 v12 原型。
- `prefers-reduced-motion` 下动画降级为静态描边。
- `Ctrl+F` 聚焦搜索、关闭隐藏、单实例等，按现有逻辑和最优实现处理。

## 二、对原报告核心冲突的逐条回复

### 1. 数据模型冲突

- 做数据迁移。
- 加列：`title`、`kind`、`tags`、`projects`、`from_view`、`nodes_json`。
- 旧数据默认 `title=''`、`kind='note'`、`tags='[]'`、`projects='[]'`。
- 旧库必须无损打开。
- 迁移机制加 `schema_migrations` 版本号，按增量迁移做。
- 标签 / 项目用 JSON 列还是关联表，`nodes_json` 还是拆表，由你按最优性能、最强兼容自行决定。个人便签量级下，JSON 列够用；以后量大再上关联表。

### 2. 持久化

- localStorage 只是原型。
- 正式必须回 SQLite。
- `seed()` 演示数据不进生产。

### 3. 事件一致性

- 必须扩展。
- `ChangedPayload` 要带 `title / kind / tags / projects`，或新增 `notes://tree-changed`、`notes://tags-changed`。
- `applyChangedPayload` 要支持新字段，保证乐观更新幂等合并。
- 继续保留 `version` 机制，避免重复插入、多聚焦卡顿。
- 具体事件怎么分、字段怎么加，你按最优实现自行决定。

### 4. 工作台角标统计

- 原报告问“outline 是否计入 active”，我解释一下：这就是工作台角标统计正常便签数和回收站数。
- 我的决定：**视图 outline 单独计数，不混进便签 active。**
- 工作台角标只数便签，视图另算。
- 这样语义清楚，避免便签数和视图数混在一起。

### 5. 搜索

- 搜 `title + text`。
- 叠加标签多选 AND、项目多选 OR。
- 特殊字符 `% _ \` 的 `ESCAPE` 处理要正确。
- 标签 / 项目过滤放前端还是后端，以性能最优、速度最快为准，你自行决定。
- 空结果文案按实际界面处理。

### 6. 3D 折叠

- 不是需求冲突，是布局重构。
- 直接照搬 v12 的 CSS 变换。
- `.panel` 从 flex 改绝对定位 + `perspective`，接受重构。
- 动画互斥锁、时间常量、缓动曲线，按原型照搬。
- 具体实现你按最优兼容自行处理。

### 7. 摘要长度

- 28 字改 20～40 字，20 字够用。
- 不搞 90。
- 有标题时按标题 + 缩略处理。
- 相关单测同步调整。

### 8. 搜索语义

- 旧版只搜正文，新版搜 `title + text`，并叠加标签 / 项目过滤。
- 其他按最优实现。

### 9. 恢复行为

- 留回收站，不跳回，不选中。
- 与 v12 相反，以我的口径为准。

### 10. 底部按钮语义

- 卡片模式新建便签。
- 视图模式新建视图。
- 地位对等。

### 11. 原型特有项

- `seed()` 不进生产。
- `localStorage` 不进生产。
- Launcher 不要。
- 响应式缩放保留。
- 其他原型环境产物不照搬。
