#### 1.1 为什么没有 —— 业务模型就是「人 → 便签」

| **唯一的程序化写入口** | 🔴 **没有** | `src-tauri/src/notes/http.rs:5`（注释：「没有任何写路由」）· `http.rs:130-132`（非 GET → **405**） |

**→ 写入口只有它自己的 UI 一个，而 UI 的输入源是人。**

#### 5.2 🔴 编译期硬编码的「默认项目根」

| 项 | 内容 |
| --- | --- |
| **我从哪拿** | `default_project_dir()` —— **编译期**取 `CARGO_MANIFEST_DIR` 的**上两级** |
| **本机实测值** | `D:\MyProject` |
| **证据** | `src-tauri/src/notes/summary.rs:19-26` |
| **拿来干嘛** | ① `list_project_folders()` 列举它的**直接子目录**作为项目候选（`src-tauri/src/notes/commands.rs:111`）② `get_meta_index` 把它当 `default_project` 一并发给前端（`src-tauri/src/notes/commands.rs:26`）③ 前端据此**隐藏"指向默认根本身"的卡片项目标记**（`src/notes/components/Card.tsx:39-40`，`samePath` 在 `:18`） |
| **我假设它是什么样** | 🔴 **二进制所在目录的布局必须保持 `…\MyProject\Note\src-tauri\`** —— 它是**编译期**用 `env!("CARGO_MANIFEST_DIR")` 算出来的，**不是运行时探测的**。<br>**坏了会怎样**：换机器 / 挪目录 / 改仓库结构 → 默认项目根指向**别的**目录：项目下拉候选变成那个目录的内容；"默认根不显示标记"的判据同时失效。🔴 **不报错，是静默错。** |

> ⚠️ **与 [data.md](data.md) 登记的那条不是一回事**：
> 那条是**运行时配置**（工作台 `tools.json` 写死本 exe 绝对路径），**改配置文件就能修**；
> **这一条是编译期常量，必须重新编译才能改。**
